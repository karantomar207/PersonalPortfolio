Privacy Policy

Your data. Your browser. Your control.

This policy explains how the FillOnce Chrome extension handles profile information, job application forms, documents, settings, and optional Answer Memory records.

Effective: July 31, 2026 Product: FillOnce Chrome Extension Developer: Karan Singh Tomar

Quick Summary

  • Profile and Answer Memory records stay in local extension storage.
  • Document files stay in extension-owned IndexedDB.
  • FillOnce does not transmit application data to a FillOnce server.
  • Answer Memory and automatic remembering are off by default.

1. Scope

This Privacy Policy applies to the FillOnce Chrome extension and its Profile Memory, document attachment, form-filling, settings, and optional Answer Memory features. “FillOnce,” “we,” and “the extension” refer to the product developed by Karan Singh Tomar.

2. Information FillOnce Handles

Depending on what you choose to configure, enter, or save, FillOnce may process the following information locally:

Identity & contact

Name, preferred name, pronouns, email, phone, address, and professional links.

Professional information

Employment, education, skills, availability, preferences, referrals, work authorization, and sponsorship.

Optional sensitive information

Compensation, citizenship or visa information, disability, veteran status, gender, race, ethnicity, and other demographics you explicitly configure.

Documents

Resumes, cover letters, profile images, filenames, file types, sizes, and last-modified dates.

Form & site context

Field labels, questions, options, section headings, website hostname, and application-platform context needed to match fields.

Answer Memory & settings

Approved questions and answers, scopes, reuse modes, confidence settings, feature toggles, and usage timestamps.

3. How Information Is Used

FillOnce uses this information only to detect and review job application fields, match them with values you configured, attach documents you selected, preserve existing answers, and provide optional Answer Memory functionality.

FillOnce never submits an application automatically. You are responsible for reviewing every value, attachment, answer, certification, and consent before submission.

4. Answer Memory Choices

Answer Memory is off by default. While off, FillOnce does not observe answers for Answer Memory and does not reuse stored Answer Memory records. You can turn it on or off in the popup or Profile Settings.

Experimental automatic remembering is a separate setting and is also off by default. Restricted questions—including passwords, OTPs, payment or bank details, government identifiers, CAPTCHAs, signatures, legal certifications, and consent fields—are not stored in Answer Memory.

5. Local Storage and Transmission

Profile data, settings, and Answer Memory records are stored with chrome.storage.local. Document bytes are stored in extension-owned IndexedDB.

FillOnce does not transmit this data to FillOnce-operated servers or third parties. Your browser, operating system, device administrator, backup tools, or browser-profile configuration may handle local browser data under their own settings and policies.

6. Sharing, Sale, Advertising, and Human Access

FillOnce does not sell, rent, trade, or share extension data for advertising, creditworthiness, profiling, or unrelated purposes. It does not use personalized advertising. Because FillOnce does not receive the extension data stored on your device, FillOnce personnel do not have routine access to it.

7. Why FillOnce Requests Permissions

Storage

Stores your profile, settings, and optional Answer Memory records locally.

Website access

Detects job application controls, reads labels and options, applies requested values, attaches local documents, and supports optional Answer Memory.

Web navigation

Identifies frames inside the active application page so FillOnce can work with embedded forms. FillOnce does not request Chrome’s browsing-history permission.

8. Your Controls

  • Turn Answer Memory on or off at any time.
  • Keep automatic remembering disabled and approve new answers individually.
  • Review, edit, disable, or delete individual Answer Memory records.
  • Edit or clear saved profile fields.
  • Export profile and Answer Memory data as JSON; document bytes are intentionally excluded.
  • Remove FillOnce and its local extension storage through Chrome.

9. Retention

Information remains in local extension storage until you edit or delete it, clear the extension’s storage, or uninstall FillOnce. FillOnce does not retain a server-side copy. Browser behavior may differ for device backups or managed profiles.

10. Security

FillOnce limits application-data handling to local extension storage and does not include analytics or remotely hosted executable code. No storage method is completely secure, so keep Chrome, your operating system, and your device access controls up to date.

11. Children’s Privacy

FillOnce is intended for people completing employment applications and is not directed to children under 13. FillOnce does not knowingly operate a server that collects children’s extension data.

12. Changes to This Policy

If FillOnce’s data-handling practices change, this policy and any required in-product disclosures will be updated before the changed practice begins. The effective date above identifies the latest revision.
